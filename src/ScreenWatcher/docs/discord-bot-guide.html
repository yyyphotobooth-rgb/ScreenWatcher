คู่มือสร้างบอท Discord ของคุณเอง

ใช้เวลาราว 5 นาที ทำครั้งเดียว ฟรีทั้งหมด บอทนี้เป็นของคุณคนเดียว และทำงานเฉพาะตอนที่เปิดโปรแกรม ScreenWatcher อยู่

ป้ายสีส้ม ยังไม่ได้ยืนยัน แปลว่าชื่อปุ่มตรงนั้นยังเทียบกับคู่มือทางการของ Discord ไม่ได้ (หน้านั้นต้องล็อกอินก่อน) ชื่อจริงบนหน้าจออาจต่างไปเล็กน้อย ให้มองหาปุ่มที่ความหมายใกล้เคียงกัน

ส่วนที่ 1 · สร้างบอท

  1. เปิดเว็บ discord.com/developers/applications แล้วล็อกอินด้วยบัญชี Discord ปกติของคุณ
  2. กดปุ่ม New Application (มุมขวาบน) ตั้งชื่อบอท เช่น ยามเฝ้าเกม ติ๊กยอมรับเงื่อนไข แล้วกด Create
    ยังไม่ได้ยืนยัน: ชื่อปุ่ม New Application และช่องติ๊กยอมรับเงื่อนไข (ยืนยันแล้วว่าขั้นสุดท้ายคือกด Create)
  3. เมนูด้านซ้าย กด Bot แอปที่สร้างใหม่จะมีบอทให้อยู่แล้ว ไม่ต้องสร้างเพิ่ม
  4. ในหัวข้อ Token กด Reset Token แล้วกดยืนยัน ระบบจะแสดงรหัสบอท (ตัวอักษรยาวๆ) เพียงครั้งเดียว ให้กดคัดลอกทันที
    ยังไม่ได้ยืนยัน: ปุ่ม Copy และการถามรหัสผ่าน/รหัสยืนยันสองชั้นก่อนแสดงรหัส
    ถ้าเผลอปิดไปก่อนคัดลอก ก็กด Reset Token ใหม่ได้ รหัสเก่าจะใช้ไม่ได้อีก
  5. ในหน้า Bot เดียวกัน หัวข้อ Privileged Gateway Intents ไม่ต้องเปิดอะไรเลย ปล่อยปิดไว้ทั้งหมด ScreenWatcher ไม่อ่านข้อความแชทและไม่ดูรายชื่อสมาชิก
  6. กลับไปที่โปรแกรม ScreenWatcher → ตั้งค่า → ขั้นที่ 2 วางรหัสบอท แล้วกด เชื่อมต่อ
    รหัสบอทเหมือนรหัสผ่าน อย่าส่งให้ใคร อย่าโพสต์ลงแชท โปรแกรมเก็บรหัสแบบเข้ารหัสไว้ในเครื่องนี้ ใช้ได้เฉพาะบัญชี Windows ของคุณ

ส่วนที่ 2 · ห้องสำหรับแจ้งเตือน และเชิญบอทเข้าห้อง

  1. ถ้ายังไม่มีเซิร์ฟเวอร์ส่วนตัว ให้สร้างฟรีในแอป Discord: กดปุ่ม + ที่แถบซ้ายสุด → Create My Own → For me and my friends ตั้งชื่อ แล้วกดสร้าง
    ยังไม่ได้ยืนยัน: ชื่อปุ่มสร้างเซิร์ฟเวอร์ทั้งหมดในขั้นนี้ (ยืนยันแล้วว่าสร้างเซิร์ฟเวอร์ได้ฟรี)
  2. (ไม่บังคับ) สร้างห้องข้อความใหม่สำหรับแจ้งเตือนโดยเฉพาะ เช่น #แจ้งเตือนเกม
  3. หลังกดเชื่อมต่อในขั้นที่ 2 ถ้าบอทยังไม่อยู่ในเซิร์ฟเวอร์ไหน โปรแกรมจะมีปุ่ม เชิญบอทเข้าเซิร์ฟเวอร์ ในขั้นที่ 3 กดแล้วเว็บ Discord จะเปิดขึ้นมา
    เลือกเซิร์ฟเวอร์ของคุณ กด Continue แล้ว Authorize สิทธิ์ที่ขอมีแค่ 3 อย่าง: ดูห้อง, ส่งข้อความ, แนบไฟล์
    คุณต้องเป็นเจ้าของเซิร์ฟเวอร์ หรือมีสิทธิ์ "Manage Server" ถึงจะเพิ่มบอทได้ (ยืนยันแล้ว)
    ยังไม่ได้ยืนยัน: ชื่อปุ่ม Continue / Authorize
  4. กลับมาที่โปรแกรม ขั้นที่ 3 เลือกห้องจากรายการ แล้วกด ทดสอบส่ง ข้อความทดสอบควรเข้ามาในห้องนั้น
  5. พิมพ์ /ss ในห้องนั้น บอทจะส่งภาพจอเกมตอนนั้นกลับมา (คำสั่งนี้ใช้ได้ทันทีหลังเลือกห้อง ยืนยันแล้วว่าคำสั่งระดับเซิร์ฟเวอร์ใช้ได้ทันที)

ส่วนที่ 3 · ให้แจ้งเตือนเด้งเข้ามือถือ

  1. ติดตั้งแอป Discord ในมือถือ แล้วล็อกอินบัญชีเดียวกัน และอนุญาตให้แอป Discord แจ้งเตือนได้ในการตั้งค่ามือถือ
  2. ในแอปมือถือ เข้าเซิร์ฟเวอร์ของคุณ กดค้าง ที่ห้องแจ้งเตือน → Notification Settings (การตั้งค่าการแจ้งเตือน) → เลือก All Messages (ข้อความทั้งหมด)
    ยังไม่ได้ยืนยัน: ชื่อเมนูในแอปมือถือทั้งหมดในขั้นนี้
  3. ตรวจว่าเซิร์ฟเวอร์และห้องนั้น ไม่ได้ถูกปิดเสียง (Mute)
  4. กด ทดสอบส่ง ในโปรแกรมอีกครั้ง ข้อความควรเด้งเข้ามือถือ
    ถ้าเปิด Discord ค้างไว้บนคอมและกำลังใช้งานอยู่ Discord อาจไม่ส่งแจ้งเตือนเข้ามือถือ ลองปิด Discord บนคอม หรือทิ้งไว้สักพักแล้วทดสอบใหม่
    ยังไม่ได้ยืนยัน: เงื่อนไขเรื่องเด้งเข้ามือถือเฉพาะตอนไม่ได้ใช้คอม

ถ้ามีปัญหา

  • "รหัสบอทไม่ถูกต้อง": กลับไปหน้า Bot กด Reset Token แล้ววางรหัสใหม่
  • ไม่มีห้องให้เลือก: บอทยังไม่มีสิทธิ์ส่งข้อความในห้องไหน กดปุ่มเชิญอีกครั้ง หรือให้สิทธิ์ห้องนั้นแก่บอท
  • แจ้งเตือนมาเฉพาะตอนเปิดโปรแกรม: ใช่ บอทอยู่ในโปรแกรมนี้ ปิดโปรแกรมแล้วบอทจะออฟไลน์

ตรวจขั้นตอนกับเอกสารทางการของ Discord (docs.discord.com/developers) เมื่อ 18 พ.ย. 2026
